# Simple Web Form (HTML and CSS)

This project provides the HTML and CSS code for a basic web form, designed to emulate the appearance of a Google Form, and implemented without the use of JavaScript.

## Project Files

* `form.html`: This file contains the HTML markup for the form, including the following input fields:
    * Full Name
    * Contact Number
    * Address
    * Company Name
    * Email Address
    * Department (dropdown select menu)
    * Gender (radio button group)
    * Form submission button
* `styles.css`: This file contains the CSS stylesheet for the form, defining:
    * Layout and spacing
    * Styling of form elements
    * Hover effect for the submission button
    * Page background color
    * Box-shadow for the form container

## Features

* Standards-compliant HTML5 structure
* CSS-based styling for a clean and user-friendly interface
* Responsive layout for adaptability across various screen sizes
* Interactive hover effect for the submission button
* Box-shadow for enhanced visual separation
* Demonstration of form creation using HTML and CSS exclusively

## Instructions

1.  Ensure that the `form.html` and `styles.css` files are located in the same directory.
2.  Open the `form.html` file in a web browser.

## Notes

* This form does not include client-side data validation or submission handling, which would typically require JavaScript. The `action="#"` attribute in the `<form>` tag will cause the page to reload upon form submission.
* The styling of this form is intended to approximate the visual style of a basic Google Form, and is provided for demonstration purposes.
